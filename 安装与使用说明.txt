精力重启 · 28 天小助手  —  安装与使用说明
================================================

【这是什么】
一个卡通风、离线可用、开源免费的小软件，帮你每天完成睡眠、专注、运动、饮食的小目标，
把状态一点点调回来。纯 HTML/CSS/JS 编写，不需要联网，不收集任何数据。

【方式一：手机上直接打开（最简单）】
1. 把「精力重启-单文件版.html」发送到手机（微信文件传输助手 / QQ / 数据线 / 网盘都可以）；
2. 用手机浏览器打开这个文件：
   · Android：Chrome / Edge / 夸克等浏览器都可以，打开后还能「添加到主屏幕」；
   · iPhone：文件 App 里选择该文件 → 共享 → 用 Safari 打开。
3. 打开就能用，完全离线；打卡数据保存在浏览器本地。

【方式二：安装成手机 App（PWA，体验最好）】
1. 把整个文件夹部署到任意静态网站（GitHub Pages、Netlify Drop、Vercel 或自己的服务器）；
   也可以电脑上进入文件夹执行：python -m http.server 8080
2. 手机浏览器打开网站：
   · Android Chrome / Edge：右上角菜单 → 添加到主屏幕 / 安装应用；
   · iPhone Safari：分享按钮 → 添加到主屏幕。
3. 以后从桌面图标打开，就是全屏 App 的样子，断网也能用。

【数据与备份】
· 打卡数据只保存在你手机/电脑的浏览器本地，不会上传网络；
· 换手机或清理浏览器前，先在「我的 → 导出备份」保存 JSON，之后用「导入备份」恢复；
· 单文件版也可以正常保存数据（同一浏览器内）。

【想自己改】
· 每日清单、28 天计划、贴士内容：改 js/app.js；
· 颜色、圆角、字体：改 css/style.css 开头的 :root 变量；
· 改完运行 python tools/build_single.py 重新生成单文件版。
